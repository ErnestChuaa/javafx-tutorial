# Duke JavaFX tutorial

This project contains the completed GUI from the SE-EDU JavaFX tutorials:

- JavaFX application and launcher setup
- Responsive chat layout with `ScrollPane`, `VBox`, `TextField`, and `Button`
- User and Duke dialog boxes with avatar images
- Enter-key and Send-button interaction with automatic scrolling
- FXML views and controller classes
- JavaFX CSS styling, hover/pressed button states, dialog bubbles, shadows, and command-based reply colors

Use JDK 25, then run the application with:

```text
gradlew.bat run
```

Build and verify the project with:

```text
gradlew.bat build
```

Tutorial reference: https://se-education.org/guides/tutorials/javaFxPart1.html
